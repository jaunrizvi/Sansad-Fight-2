# SANSAD FIGHT — Prototype 2

A mobile-first browser game prototype by **Mohd Jaun Rizvi**.

## What's new
- Your 7.93-second opening cinematic is integrated as `assets/sansad_intro.mp4`.
- Your Indian Phonk track is integrated as looping background music: `assets/sansad_theme.m4a`.
- Tap **PLAY INTRO WITH SOUND** to start both. Mobile browsers require this tap before audio can play.
- The video plays once, then the main menu appears. **SKIP INTRO** opens the menu.
- Music can be muted/unmuted from the top bar.
- Your SANSAD FIGHT poster is used as the intro poster/fallback.

## Run on Android
1. Extract the ZIP.
2. Open the `SANSAD_FIGHT` folder in Acode.
3. Keep the `assets` folder beside `index.html`; do not move or rename its files.
4. Preview `index.html` in Chrome while connected to the internet. Three.js is loaded from jsDelivr CDN.
5. Rotate the phone to landscape for gameplay.

## Publish with GitHub Pages
Upload the complete contents of the `SANSAD_FIGHT` folder to the root of a GitHub repository (including `assets/`), then enable GitHub Pages in Settings → Pages.

## Current limitations
This is still an early playable prototype, not a finished commercial-quality 3D fighting game. Fighters are procedural placeholders. Custom character models, polished animations, crowd systems, advanced CPU behaviour, complete local two-player touch controls, and final sound design remain future development tasks.
